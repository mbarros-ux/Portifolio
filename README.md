## Sobre
Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e experiências profissionais. Este site foi criado com HTML, CSS e JavaScript puro, servindo como cartão de visitas digital para oportunidades em desenvolvimento de software.

O portfólio está em constante atualização conforme novos projetos e experiências são adicionados.

## Tecnologias Utilizadas
- HTML5 - Estrutura semântica e acessível
- CSS3 - Design moderno, responsivo e animações
- JavaScript - Interatividade e navegação suave

## Funcionalidades
- Design responsivo (mobile, tablet e desktop)
- Navegação suave entre seções
- Seção de projetos com links para demos ao vivo
- Seção de habilidades técnicas
- Histórico de experiências profissionais
- Informações de formação acadêmica
- Links de contato (GitHub, LinkedIn, Email)
- Animações e transições CSS
